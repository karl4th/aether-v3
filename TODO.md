## Зафиксированные решения

- Текущий проект строит качественный MVP, а не финальный production продукт.
- Текущий frozen-Qwen R1 run уже считается успешным для MVP.
- Три recovery eval являются дополнительной попыткой улучшить checkpoint и не
  отменяют успешный результат основного run.
- LoRA не является обязательным условием текущего MVP.
- После investor demo приоритет переходит к улучшению Stage 1, затем к новому
  проходу Stage 2.
